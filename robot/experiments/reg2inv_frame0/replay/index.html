        How Reg2Inv scores against frame 0

        Open one to see what is compared with what, and how the point, frame and video values are computed.

        The normal referenceframe 0, per video and link

        What it is. The video's own frame-0 observed cloud of the link, frozen before any later frame is seen. No CAD model, mesh or later-frame point enters it. Frame 0 is assumed normal; it is not verified healthy geometry.

        How it is made. MegaSAM depth inside the link mask is back-projected and filtered by the shared Link5 ray-normalized density filter. Link2 then drops detached mask islands whose median depth differs from the main island's by more than 0.25 m: background seen through gaps in the mask. Every later Link2 frame gets the same filter.

        What Reg2Inv keeps from it. The cloud's radius and centre normalize every query frame. Reg2Inv's pretrained network turns it into feature points; all of them (the coreset limit is the feature count) form the memory bank of normal patches.

        Point scorethe colour of each dot

        Registration. Each frame's cloud is registered to the reference by Reg2Inv's RANSAC over feature correspondences (50,000 iterations, float64 GPU evaluation). Aligned to frame 0 draws the points with that transform.

        Patch score. For each feature point, the feature is its registered position (divided by the reference's position norm) joined with Reg2Inv's 32-dimensional invariant shape feature (divided by the shape norm). Its patch score is the distance to the nearest feature in the memory bank.

        s(p) = mean of the patch scores of the 16 feature points nearest to p

        In the replay. White is about 0; the red end is the 95th percentile of all point scores after frame 0, shared by every video and both links. The replay shows one point of every 2 × 2 depth-grid block; scores are not altered.

        Frame and video scorethe chart and the index

        Frame score. Average each feature point's patch score over its 64 nearest feature points, then take the largest. This is the chart. A frame with fewer than 64 selected feature points has no score.

        Video score. The mean of the link's frame scores over the clip, including frame 0. The index also lists the largest frame score and where it occurs. AUROC uses the video mean.

        What it can miss. The score measures change from frame 0. A deformation already present at frame 0 is part of the normal reference, and surfaces that only become visible later have no reference coverage.
