Prompts and provenance

PhysicsLENS has the generator's text prompt (“Scene: … Action: …”) and the task. RoboJudge-Bench releases the instruction, not the exact prefix/rewrite prompt. MiraBench has no text prompt (first frame plus a robot action sequence), so its task description names the subset and scene. Files were downloaded from pinned Hugging Face revisions to a temporary folder, checked against the Hub checksums, copied to ERIS and checked again there with sha256sum; built by scripts/stage_existing_annotations.py.

Error groups of three published world-model evaluation sets, compared with our physics metrics. Previews are reduced H.264 copies; the unchanged videos are on Hugging Face (linked from each video page) and the full filtered sets with every annotation are on ERIS scratch.
